# 🦊 FoxCell WhatsApp Server (Baileys Gratuito 24h)

Microserviço gratuito de WhatsApp Web sem mensalidade para a FoxCell Assistência Técnica.

## Como subir no Render.com (100% Grátis):
1. Crie uma conta gratuita no [render.com](https://render.com) (pode entrar com Google ou GitHub).
2. Clique em **New +** > **Web Service**.
3. Escolha **Deploy from Git repository** (ou suba esta pasta).
4. Configure:
   - **Environment:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** Free (R$ 0,00)
5. Clique em **Create Web Service**!
6. Copie a URL gerada (ex: `https://foxcell-zap.onrender.com`) e cole nas configurações do seu sistema FoxCell.
